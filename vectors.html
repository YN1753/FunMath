第 7 站 · 平面向量

🧭向量：既有大小又有方向的量

向量是"会指路的数"。加法怎么走、点积衡量什么——箭头一拖，全在图上。

实验 1向量加法 / 减法

拖动蓝、绿箭头的端点。加法：红色对角线 = a + b（平行四边形法则）；减法：连接两个箭头端点的虚线 = a − b（指向被减数）。

a = (2, 1) b = (1, 2) a + b = (3, 3)

📖 知识点速览

向量的坐标与模

向量 = 有向线段：起点、方向、长度（模）。只关心方向和大小时，向量可以自由平移——这正是三角形法则能"接龙"的原因。

线性运算

  • 三角形法则：b 的起点接到 a 的终点，则 a + b 从 a 的起点指向 b 的终点。
  • 平行四边形法则：a、b 共起点，对角线 = a + b（实验 1 里的红色对角线）。
  • 减法：a − b 从 b 的终点指向 a 的终点（"指向被减数"）。

数量积（点积）：衡量"方向有多一致"

结果是一个数而不是向量：夹角锐 → 正；直角 → 0；钝角 → 负。a ⊥ b ⇔ a·b = 0，这是解析几何里证垂直的万能钥匙。
