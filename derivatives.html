导数 = 瞬时变化率 = 切线斜率。听起来抽象？在这两台"机器"里，你会亲眼看着割线缩成切线、看着导函数的图像一点一点被描出来。

导数怎么"用"？

  • 单调性：区间上 f'(x) > 0 ⇒ 增函数；f'(x) < 0 ⇒ 减函数。实验 2 里导数在 x 轴上方的那段，原函数正在"上坡"。
  • 极值：f′(x) = 0 且两侧变号处取得极值（正变负是极大，负变正是极小）。
  • 最值：比较所有极值与区间端点值。

实验 2亲手描出导函数

上半部分：原函数与切线；左右拖动橙色点（或点「自动扫描」）。下半部分会把每个位置的切线斜率记成一个点——点连起来，就是导函数 f′(x) 的图像！

🔍 检验成果：x² 的导数是一条直线（f′ = 2x）；sin x 的导数是它"左移四分之一周期"（f′ = cos x）；x³−3x 的导数是条抛物线，与 x 轴的两个交点 ±1 正好对应原函数的峰和谷。
